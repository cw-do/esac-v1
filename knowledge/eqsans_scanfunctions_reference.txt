# EQ-SANS Scan Functions Reference

This document summarizes the key functions available in `eqsans_scanfunctions_live.py` for controlling the EQ-SANS instrument.

## Beam Control Functions
- `beamstopX(pos)` - Move beamstop X position
- `beamstopY30(pos)`, `beamstopY60(pos)`, `beamstopY90(pos)` - Move beamstop Y positions for different sizes
- `beamslit1(slitname)`, `beamslit2(slitname)`, `beamslit3(slitname)` - Set beam slit configurations
- `beamslit4(slitsize)` - Set beam slit 4 size
- `setWL(wl)` - Set wavelength band
- `closeShutter()`, `openShutter()` - Control secondary shutter

## Detector and Optics
- `movedetector(detz)` - Move detector to sample-to-detector distance (in mm)
- `movemask(value)` - Move mask position
- `chopperfreq(hz)` - Set chopper frequency (30 or 60 Hz)
- `set_chopper_delay(chopper, value)` - Set individual chopper phase delays
- `set_choppers_auto()` - Set automatic chopper phases

## Sample Environment
- `movetransx(value)`, `movetransz(value)` - Move sample table translation
- `moveroth(value)` - Move rotation stage
- `tumbler(args)` - Control tumbler rotation ('on'/'start' or 'off'/'stop')
- `sethaaketemp(value)` - Set HAAKE temperature
- `setpeltier1temp(value)`, `setpeltier2temp(value)` - Set Peltier temperatures
- `settumblertemp(value)` - Set tumbler temperature
- `setfurnacetemp(value)`, `sethtfurnacetemp(value)` - Set furnace temperatures
- `set_field(value)`, `set_field_wait(value)` - Control magnetic field
- `set_freq_wait(value)`, `set_amp_wait(value)` - Control frequency/amplitude for SRS
- `set_cryostat_vti(value)`, `set_cryostat_sample(value)` - Control cryostat temperatures

## Sample Positioning
- `set_tensileg_gap(value)`, `set_tensileg_move(value)` - Control tensile stage
- `rotate_cryob(value)` - Rotate cryostat stick

## Specialized Equipment
- `setteledynepressure(value)`, `runteledynepump()`, `stopteledynepump()` - Teledyne pump control
- `sc_stop()`, `sc_setmanual()`, `sc_setcycle()`, `sc_setspeed(value)` - Sliding shear cell control
- `outletswitch(args)` - Power outlet control ('on'/'start' or 'off'/'stop')
- `psylo_tension_step(speed, dist, selector)` - PsyloTech tensile stage control

## Scan Control
- `setipts(value)` - Set IPTS number
- `setitems(value)` - Set ITEMS number
- `setruntitle(title)` - Set run title
- `start()`, `stop()` - Start/stop data acquisition
- `waitPC(value)` - Wait for proton charge
- `delay(time)` - Add delay
- `runsample(title, racktype, timetype, pos, limit)` - Run sample measurement
- `runfurnace(title, timetype, pos, limit)` - Run furnace measurement
- `runcryostat(title, timetype, limit)` - Run cryostat measurement
- `loadconf(file_name)` - Load Q-Range configuration
- `maghscanup(start, end, step, wait, title, timetype, limit)` - Magnetic field scan

## Utility Functions
- `setpv(pv, value, wait=True)` - Set any PV value
- `readpv(pv)` - Read PV value
- `estimatetime(power=1.4)` - Estimate total measurement time
- `resettime()` - Reset time counters

## Important Notes
- All functions use EPICS PVs to control instrument components
- Functions automatically log operations and submit to the scan system
- Use exact function names and parameter types as shown
- Check instrument status before using sample environment functions
- Refer to the full `eqsans_scanfunctions_live.py` file for detailed implementations and PV names
