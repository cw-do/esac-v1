3. Emergency Procedures
-----------------------

### 3.1 Emergency numbers
- From any ORNL landline: **911**
- From a mobile phone: **865-574-6606**

### 3.2 If a sample breaks after exposure
**Do NOT:**
- Touch the sample  
- Attempt to clean the sample  
- Move the broken container  

**Do:**
1. Immediately close the shutter if open  
2. Move away from the spill area  
3. Call RCTs at 865-274-8658  
4. Wait for radiation professionals to arrive  

### 3.3 If an alarm sounds
- Stop work immediately  
- Follow posted evacuation routes  
- Do not collect belongings unless instructed  
- Proceed to assembly point  
- Await further instructions

5. Required Pre-Experiment Checklist
------------------------------------

LLM should encourage users to verify the following items before running an experiment.

### 5.1 Administrative Requirements
- IPTS number is assigned and set  
- Samples are checked in and have ITEMS numbers  
- SMA (Sample Management Approval) is signed  
- ESS (Experiment Safety Sheet) is signed  
- Users are trained on EQ-SANS instrumentation  

### 5.2 Sample and Beamline Preparation
- Sample environment matches what is physically installed  
- Sample positions are calibrated  
- Pinhole aperture fully inserted  
- Beamstop is aligned for the chosen Q-range  
- Sample table is locked in place  
- Airflow is set to the desired state  
- Required control samples (empty cell, porous silica, container) are present  
- Neutron camera is removed

6. User Guidance for Instrument Operation
-----------------------------------------

### 6.1 Basic advice for running experiments
- Always verify the correct sample is in the beam  
- Confirm shutter state before taking data  
- Use descriptive and consistent sample names  
- Keep configuration transitions clean and minimal  
- Monitor counting statistics for consistency  
- Use appropriate proton charge for wavelength  
- Communicate with instrument staff if unexpected scattering patterns appear  

### 6.2 Tips for reliable data
- Ensure samples are centered and mounted securely  
- Allow sufficient temperature stabilization before measurement  
- Use proper ITEMS numbers for traceability  
- Minimize movement of sample environments  
- Document all temperature and environment changes
